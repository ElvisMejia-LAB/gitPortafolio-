# Portafolio personal — Elvis Mejía

## Cómo abrirlo
1. Descarga y descomprime `ELVIS_PORTAFOLIO.zip`.
2. Abre la carpeta `ELVIS_PORTAFOLIO` en Visual Studio Code.
3. Abre `index.html` en tu navegador. También puedes usar la extensión **Live Server** para visualizar los cambios automáticamente.

## Estructura
- `index.html`: contenido y estructura de la página.
- `css/style.css`: diseño, colores, animaciones y adaptación a dispositivos.
- `js/script.js`: menú móvil, filtros, ventanas de detalles y animaciones.
- `images/proyectos/`: carpeta para añadir capturas o fotografías de tus proyectos.
